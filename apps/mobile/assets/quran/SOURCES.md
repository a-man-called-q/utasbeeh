# Qur'an text and translation

Both files are bundled verbatim, copyright blocks included, and parsed at
runtime. Do not edit them; download a fresh copy to update.

- `quran-uthmani.txt` — Tanzil Quran Text (Uthmani, Version 1.1),
  Copyright (C) 2007-2026 Tanzil Project, licensed CC BY 3.0. Verbatim
  copies only; the source must be credited with a link to
  https://tanzil.net. Downloaded from
  https://tanzil.net/pub/download/ (pause marks, sajdah, rub el hizb and
  tatweel on; "text with aya numbers").
- `en.pickthall.txt` — The Meaning of the Glorious Koran, Marmaduke
  Pickthall (1930). Public domain (translator died 1936). Digital copy
  from Tanzil (`en.pickthall`, updated 2010-09-04).

The English translation is a stopgap until permission to use the Kemenag
Indonesian translation is granted by LPMQ.
